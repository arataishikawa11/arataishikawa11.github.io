# arataishikawa11.github.io

Personal academic website of Arata Ishikawa, Undergraduate Student in Engineering Physics at the University of California, Berkeley.

Built with [Next.js](https://nextjs.org), styled with Tailwind CSS, and hosted on GitHub Pages.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
